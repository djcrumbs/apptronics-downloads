# Age Rating — Neon Breaker

## IARC / Microsoft Store Rating

**Recommended rating: Everyone (E) / PEGI 3**

### IARC Questionnaire Answers

| Category | Answer | Notes |
|---|---|---|
| Violence | None | No characters, no harm depicted |
| Scary themes | None | Abstract neon shapes only |
| Sexual content | None | |
| Drug/alcohol references | None | |
| Language | None | UI text only (English) |
| Gambling | No | No loot boxes, no randomised paid content |
| User interaction | None | No chat, no multiplayer |
| Purchases | Yes — optional | "Neon Breaker Premium" IAP (removes ads); no consumable gambling-style items |
| Advertising | Yes | Microsoft Advertising banner + interstitial rewarded ad |

### IAP Classification

- **Product type**: Durable (permanent unlock)
- **Name**: "Neon Breaker Premium"
- **Price tier**: £1.99 / $1.99
- **What it does**: Permanently removes all advertising from the game
- **No loot boxes, no consumable currency, no social pressure mechanics**

### Content Descriptors

- In-App Purchases (advertising removal only)

### Store Age Gate

No age gate required. The game is appropriate for all ages.

### Justification

Neon Breaker is an abstract arcade game with no characters, no violence, no narrative involving mature themes, and no randomised monetisation. The only purchase is a one-time ad-removal IAP at a fixed price. This matches the Microsoft Store's definition of a "simple purchase" with no gambling elements.
